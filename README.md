***Main topic***
In this repository are the assignments for the course for BERN02, along with the results if required. Project 1 is about creating a weighted local simple regression model and applying it. Project 2 is about creating a model for Poisson regression and applying it to three random samples.

***Packages needed***
So far the only packages necessary are numpy, scipy and statsmodels.

***Motivation***
To specify the computing environment, we have used the environment.yml configuration. Every package has been installed using pip and their versions are recorded in the environment.yml file. This documentation ensures that the specific environment used to create this repository can be recreated by anyone, who chooses to do so in the future.

***Risk Assesment***
Potential risks for future users can be the following: background packages may change over time, that can affect the workings of the versions of packages that have been recorded; newer versions of python might not support certain packages used in these files; different operating systems might run into difficulties; etc.
